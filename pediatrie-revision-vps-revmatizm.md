# План ревизии

**Тема № 11:** Болезни сердца и органов кровообращения у детей: врождённые пороки сердца (ВПС) и ревматизм.
**Источники:** презентация «Врождённые пороки сердца» (44 слайда) + методические указания к занятию (аннотация, вопросы, тесты, задачи).

> **«Дополнительная информация»** = этого нет в документах, добавлено только для понимания.
> **⚠️ В источнике** = в документах есть неточность.

---

## 1. Тема и главные идеи

1. Сердце формируется на **2-й неделе** внутриутробной жизни. Начинает сокращаться на **6–8-й неделе**. Сокращения выслушиваются с **18–20-й недели**.
2. У плода **три круга кровообращения** (есть дополнительный — плацентарный) и **три плодовые коммуникации**: Аранциев проток, Боталлов проток, овальное окно.
3. **Порок сердца** — стойкое патологическое изменение в строении сердца, которое нарушает его функцию.
4. **ВПС** формируются на **2–8-й неделе беременности** (нарушение эмбриогенеза) или после внутриутробного эндокардита.
5. В России каждый год рождается около **10 тысяч** детей с ВПС. Причины: вредные привычки матери (алкоголь, наркотики), её болезни, экология.
6. Есть **4 группы ВПС** — по состоянию кровотока в малом и большом кругах.
7. В течении ВПС **3 фазы**: первичной адаптации, относительной компенсации, терминальная.
8. Общие признаки ВПС: **цианоз, одышка, шум в сердце**, увеличение сердца, частые пневмонии, отставание в физическом развитии.
9. Самый частый порок — **ДМЖП** (20–30 %). Самый частый «синий» порок — **тетрада Фалло**.
10. При тетраде Фалло опасны **одышечно-цианотические (гипоксемические) кризы**. Основа помощи — **оксигенотерапия**.
11. **Единственное лечение ВПС — операция** (радикальная или паллиативная). Лучшее время — II фаза (3–12 лет).
12. Главный метод диагностики порока — **УЗИ сердца**.
13. **Ревматизм** — системное воспалительное заболевание соединительной ткани, в основном поражает сердце и сосуды. Причина — **β-гемолитический стрептококк группы А**.
14. Ревматизм начинается через **1,5–2 недели** после ангины. Главные проявления: **кардит, полиартрит, малая хорея**.
15. Ревматизм — главная причина **приобретённых** пороков сердца. Профилактика — **бициллин-5**, режим и уход с первых дней болезни.

## 2. Основные понятия

### 2.1. Словарь

| Термин | Простое объяснение |
|---|---|
| **Порок сердца** | Стойкое изменение строения сердца, которое нарушает его работу (фр. *cardiopathie / malformation cardiaque*) |
| **ВПС** | Врождённый порок сердца — ребёнок родился с ним |
| **Малый круг** | Кровь идёт: правый желудочек → лёгкие → левое предсердие (фр. *petite circulation*) |
| **Большой круг** | Кровь идёт: левый желудочек → всё тело → правое предсердие (фр. *grande circulation*) |
| **Гемодинамика** | Движение крови по сосудам |
| **Сброс крови (шунт)** | Кровь идёт неправильным путём через отверстие |
| **Обогащение малого круга** | В лёгкие идёт слишком много крови |
| **Обеднение малого круга** | В лёгкие идёт слишком мало крови → цианоз |
| **Цианоз** | Синий цвет кожи и губ из-за нехватки кислорода |
| **Акроцианоз** | Синие пальцы, кончик носа, уши |
| **Одышка** | Трудное, частое дыхание (фр. *dyspnée*) |
| **ОАП (Боталлов проток)** | Открытый артериальный проток — сосуд между аортой и лёгочной артерией не закрылся после рождения (фр. *canal artériel persistant*) |
| **ДМПП** | Дефект (отверстие) межпредсердной перегородки |
| **ДМЖП** | Дефект (отверстие) межжелудочковой перегородки |
| **Стеноз** | Сужение |
| **Коарктация аорты (КоА)** | Сужение аорты, кровоток ограничен |
| **ТМС** | Транспозиция магистральных сосудов — аорта и лёгочная артерия «поменялись местами» |
| **Тетрада Фалло** | Порок из 4 аномалий (см. ниже) |
| **«Барабанные палочки»** | Толстые концы пальцев при долгой нехватке кислорода (фр. *hippocratisme digital*) |
| **«Часовые стёкла»** | Выпуклые круглые ногти |
| **Гипоксемический криз** | Приступ сильной одышки и цианоза |
| **Сердечная недостаточность** | Сердце не может нормально качать кровь |
| **Радикальная операция** | Полностью исправляет порок |
| **Паллиативная операция** | Только облегчает состояние, порок остаётся |
| **Ревматизм** | Системное воспаление соединительной ткани, в основном в сердце и сосудах (фр. *rhumatisme articulaire aigu*) |
| **Ревмокардит** | Ревматическое воспаление сердца |
| **Миокардит / эндокардит / перикардит** | Воспаление мышцы сердца / внутренней оболочки и клапанов / наружной оболочки |
| **Полиартрит** | Воспаление нескольких суставов |
| **Малая хорея** | Поражение нервной системы при ревматизме: непроизвольные движения (фр. *chorée de Sydenham*) |
| **Гиперкинезы** | Непроизвольные, порывистые, лишние движения |
| **Аннулярная эритема** | Розовая сыпь в виде колец |
| **Коллапс** | Резкое падение давления (острая сосудистая недостаточность) |
| **Обморок** | Короткая потеря сознания (фр. *syncope*) |
| **Диспансерное наблюдение** | Регулярный контроль в поликлинике |

### 2.2. Кровообращение плода и новорождённого

| У плода | После рождения |
|---|---|
| 3 круга кровообращения (+ плацентарный) | 2 круга |
| Аранциев (венозный) проток | становится венозной связкой |
| Боталлов (артериальный) проток | закрывается, становится связкой |
| Овальное окно | закрывается |
| Пупочная вена и пупочные артерии | становятся связками |

Если проток или окно **не закрываются** → ВПС (открытый артериальный проток, незаращение овального окна).

### 2.3. Физиологические особенности сердца и сосудов у детей

| Показатель | Норма |
|---|---|
| Просвет вен и артерий | 1 : 1 |
| Пульс | относительно частый и аритмичный → **считать 60 секунд** |
| ЧСС у новорождённого | **120–140** в минуту |
| ЧСС к 5 годам | **100** в минуту |
| АД у новорождённого | систолическое **70–75** мм рт. ст.; диастолическое = ⅔–½ от систолического |
| АД у детей старше года | АД макс = **102 + 0,5·n** (n — число лет); АД мин = от ½ до ⅔ от АД макс |

**Места выслушивания сердца (5 точек):** 1 — верхушка сердца; 2 — лёгочная артерия; 3 — аорта; 4 — трёхстворчатый клапан; 5 — точка Боткина.

### 2.4. Классификация ВПС (4 группы)

| Группа | Что происходит | Пороки |
|---|---|---|
| **I. С обогащением малого круга** | Сброс крови в правые отделы сердца и лёгочную артерию через патологическое сообщение между кругами | ОАП, ДМПП, ДМЖП |
| **II. С обеднением малого круга** | Сужение лёгочной артерии, часто + сброс крови из правого желудочка в большой круг (**шунт справа налево**) | изолированный стеноз лёгочной артерии, болезнь Фалло (триада, тетрада, пентада) |
| **III. С обеднением большого круга** | Мало крови идёт в тело | коарктация аорты |
| **IV. Без нарушений гемодинамики** | Кровоток не нарушен | — |

**«Большая пятёрка» ВПС = 65 % всех пороков:**

| Порок | Относительная частота, % | Частота критических состояний, % |
|---|---|---|
| ДМЖП | 26 | 21 |
| Коарктация аорты | 8 | 64 |
| Транспозиция магистральных сосудов | 8 | **100** |
| ОАП | 7 | 30 |
| Тетрада Фалло | 7 | 35 |

> ⚠️ **В источнике:** в таблице написано «ДЖМП» — это опечатка, правильно ДМЖП.

### 2.5. Три фазы течения ВПС

| Фаза | Что происходит |
|---|---|
| **1. Первичной адаптации** | Организм приспосабливается к нарушениям гемодинамики |
| **2. Относительной компенсации** | Наступает через **2–3 года**. Состояние, физическое развитие и активность ребёнка заметно улучшаются. **Лучшее время для операции** |
| **3. Терминальная** | Компенсаторные возможности закончились. Дистрофия и дегенерация сердечной мышцы. Заканчивается смертью |

## 3. Клиническая картина

### А. Врождённые пороки сердца

**Общие признаки ВПС:**
- **цианоз** (постоянный, преходящий или временный);
- **одышка**;
- **шум** над сердцем и сосудами;
- границы сердца увеличены;
- частые респираторные инфекции и затяжные повторные пневмонии;
- отставание в физическом развитии.

**Признаки отдельных пороков:**

| Порок | Главные признаки |
|---|---|
| **ОАП** | Одышка, утомляемость, боли в сердце. Максимальное АД в норме, **минимальное АД низкое** (особенно стоя). **Пульс скачущий**. Дрожание грудной клетки при пальпации. Сердце расширено **влево и вверх**. Систолический **«машинный» шум**, проводится на аорту, шейные сосуды, в межлопаточную область |
| **ДМПП** | Тяжесть зависит от размера дефекта. Одышка, утомляемость. Кожа **бледная**. Сердце расширено в поперечном размере, **больше вправо**. Систолический шум во **II–III межреберьях слева** от грудины |
| **ДМЖП** | **1-е место** по частоте (20–30 %). Сброс крови **из левого желудочка в правый**. Две формы: **высокие** дефекты (в мембранозной части) и **малые** дефекты в мышечной части (**болезнь Толочинова–Роже**). Одышка, **кашель**, слабость, утомляемость, частые респираторные инфекции, отставание в развитии. Кожа бледная, при крике — **лёгкий цианоз**. Увеличен поперечный размер сердца. Длительный систолический шум в **III–IV межреберьях слева**, проводится на всю область сердца. Небольшой дефект в мышечной части гемодинамику **не нарушает** |
| **Изолированный стеноз лёгочной артерии** | Одышка. Сердце расширено **вправо**. **Грубый систолический шум во II межреберье слева**, проводится в левую подключичную область и на сонные артерии. На рентгене: обеднение лёгочного рисунка |
| **Тетрада Фалло** | См. ниже |
| **Коарктация аорты** | Сужение аорты ограничивает кровоток в нижнюю часть тела. Диагностика — аортография. **Дополнительная информация:** высокое АД на руках, низкое на ногах, слабый пульс на бедренных артериях |

**Тетрада Фалло — самый частый «синий» порок. 4 аномалии:**
1. **стеноз лёгочной артерии**;
2. **дефект межжелудочковой перегородки**;
3. **транспозиция (смещение) аорты вправо**;
4. **гипертрофия правого желудочка**.

**Клиника тетрады Фалло (сразу после рождения):**
- **одышка и цианоз**;
- **вынужденная поза**: ребёнок **садится на корточки** или лежит на боку с поджатыми к животу ногами (так меньше одышка);
- пальцы — **«барабанные палочки»**, ногти — **«часовые стёкла»**;
- отставание в физическом развитии;
- границы сердца нормальные или немного расширены влево;
- **грубый систолический шум**;
- в крови **повышены гемоглобин и эритроциты**.

**🚨 Одышечно-цианотический (гипоксемический) криз** — при декомпенсации порока:
- на фоне обычного акроцианоза — **приступ одышки**;
- **тахикардия**;
- **цианоз усиливается**;
- ребёнок **возбуждён**;
- часто **обморок**;
- потом возможна **гипоксическая кома** с потерей сознания и **судорогами**.

### Б. Ревматизм

**Причина:** β-гемолитический стрептококк группы А + генетическая предрасположенность + аллергические реакции. Антигены стрептококка поражают оболочки сердца и сосуды. Образуются аутоантитела, они дальше повреждают соединительную ткань.

**Начало:** через **1,5–2 недели** после стрептококковой инфекции (ангина). Температура, интоксикация, поражение сердца и других систем.

**Особенность у детей:** одновременно поражаются миокард, эндокард и перикард. Порок сердца может сформироваться даже при лёгком и скрытом течении.

**Поражение сердца (ревмокардит):**

| Форма | Признаки |
|---|---|
| **Диффузный миокардит** | Состояние резко ухудшается. Бледность, одышка, цианоз. Пульс частый, аритмичный. АД снижено. Границы сердца расширены. Мягкий систолический шум на верхушке. Застой в малом круге: мелкопузырчатые хрипы в лёгких. Застой в большом круге: увеличение печени, асцит, отёки на ногах |
| **Очаговый миокардит** | Состояние удовлетворительное. Границы сердца в норме, тоны немного приглушены. Слабый систолический шум на верхушке. Недостаточности кровообращения нет |
| **Эндокардит** | Поражаются клапаны, чаще всего **митральный**. Грубый систолический шум на верхушке и в V точке, проводится в подмышечную область. При поражении аортального клапана — «льющийся» диастолический шум вдоль левого края грудины |
| **Перикардит** | Отдельно бывает редко. Фибринозный: боли в сердце, **шум трения перикарда**. Экссудативный: резкое ухудшение, бледность, цианоз губ, набухание шейных вен, одышка, **вынужденное положение сидя**, пульс частый и слабый, АД снижено, тоны глухие, сердечно-сосудистая недостаточность. На рентгене — большая тень сердца трапециевидной формы |

**ЭКГ при миокардите:** нарушения ритма, снижение и деформация зубца Т, удлинение P–Q, расширение QRS, смещение S–T вниз.

**Внесердечные поражения:**

| Поражение | Признаки |
|---|---|
| **Ревматический полиартрит** | 1) **крупные суставы** (колени, голеностопы, плечи, локти, лучезапястные), **симметрично**; 2) развивается очень быстро, за несколько часов; кожа отёчная, красная, горячая; 3) сильная боль, ребёнок не может встать; 4) без лечения проходит сам через неделю, но могут воспалиться другие суставы. Всего длится **4–5 недель**. Суставы потом остаются **без изменений** |
| **Малая хорея** | Начало постепенное: раздражительность, плаксивость, плохой сон. Через 1–2 недели: **гиперкинезы**, **гипотония мышц**, **некоординированность движений**, нарушения эмоций. Гримасы, ребёнок не может сам есть, меняется почерк. Тяжёлая форма — «двигательная буря»: не может стоять и ходить; могут страдать глотание и речь. Сердце поражено умеренно, температура нормальная |
| **Кожа** (редко) | **Аннулярная эритема**, **ревматические узелки** |

**Фазы:** активная и неактивная. Активная фаза длится **10–12 месяцев**.

**Степени активности:**

| Степень | Признаки |
|---|---|
| **I — минимальная** | Клинические, лабораторные и инструментальные признаки слабо выражены |
| **II — умеренная** | Признаки умеренные. Лихорадки может не быть |
| **III — максимальная** | Признаки яркие. Высокая лихорадка. Чёткие признаки кардита на ЭКГ. Резко изменены анализы |

**Течение активной фазы:** острое (до 2 месяцев), подострое (до 3–4 месяцев), затяжное (до 5–6 месяцев), рецидивирующее (1 год и более), латентное (без симптомов).

### В. 🚨 Сигналы тревоги (для медсестры)

- усиление цианоза и одышки, особенно при плаче или нагрузке;
- ребёнок садится на корточки;
- приступ одышки + тахикардия + возбуждение → **криз**;
- потеря сознания, судороги;
- отёки, увеличение печени, хрипы в лёгких → **сердечная недостаточность**;
- при ревматизме: резкая бледность, одышка, набухание шейных вен, положение сидя;
- резкая бледность, липкий холодный пот, нитевидный пульс, низкое АД → **коллапс**.

## 4. Диагностика

### А. ВПС

- осмотр, аускультация (шум);
- **УЗИ сердца — самый важный метод**;
- электрокардиография и фонокардиография;
- рентген сердца и сосудов;
- ангиокардиография (аортография при коарктации);
- зондирование сердца.

### Б. Ревматизм

**Основные диагностические критерии:**
- **кардит**;
- **полиартрит**;
- **хорея**;
- **ревматические узелки, аннулярная эритема**;
- связь с перенесённой **стрептококковой инфекцией**.

**Дополнительные критерии:**
- лихорадка;
- артралгия (боль в суставах);
- лабораторные изменения;
- изменения на ЭКГ;
- ревматический анамнез (ревматизм в прошлом, ревматическое поражение сердца).

**Лабораторная диагностика:**
- общий анализ крови: **лейкоцитоз, повышенная СОЭ**;
- биохимия: диспротеинемия, **С-реактивный белок**, повышение фибриногена и серомукоида;
- рост титров противострептококковых антител: **АСЛ-О**, АСГ, АСК;
- выделение стрептококка группы А из зева.

## 5. Лечение

### А. ВПС

**Единственное средство лечения — хирургическая операция.**

| Вид операции | Смысл |
|---|---|
| **Радикальная** | Полностью исправляет порок |
| **Паллиативная** | Облегчает состояние, предотвращает раннюю смерть |

**Лучший срок операции:** II фаза течения порока (**3–12 лет**). Можно оперировать и раньше.

**Задачи консервативной терапии:**
1. неотложная помощь при катастрофических состояниях: **сердечной недостаточности** и **гипоксемических кризах**;
2. поддерживающее лечение;
3. профилактика тромбозов;
4. лечение анемий.

**Поддерживающая терапия:** сердечные гликозиды в небольших дозах, рибоксин, АТФ, кокарбоксилаза, препараты калия.

**Профилактика тромбозов:** ацетилсалициловая кислота, дезагреганты (риск тромбоза при ВПС большой).

### Б. 🚨 Лечение гипоксемического (одышечно-цианотического) криза

**Основа лечения:**
1. **оксигенотерапия** (лучше с постоянным положительным давлением на выдохе);
2. **коррекция ацидоза** — 4 % раствор натрия гидрокарбоната;
3. лекарства против **спазма начальных отделов лёгочной артерии**.

**Порядок:**
- начинают с **морфина или промедола**;
- если нет эффекта — **обзидан**;
- при судорогах — **натрия оксибутират** (он ещё защищает от гипоксии);
- ❌ **сердечные гликозиды и диуретики противопоказаны!**
- длительные и тяжёлые приступы с потерей сознания → **экстренная госпитализация в кардиохирургическое отделение**.

### В. Ревматизм

Лечение **комплексное, длительное, этапное**: стационар → ревматологический санаторий → дома под наблюдением ревматолога.

**1. Режим:**

| Активность | Режим |
|---|---|
| Максимальная | **строгий постельный** (1а) |
| Умеренная или минимальная | **постельный**, 2–3 недели |
| Потом | полупостельный или щадящий (2а) |
| За 2 недели до выписки | домашний или тренирующий |

Рано назначают лечебную физкультуру.

**2. Диета:** полноценная, с витаминами и **калием**. В остром периоде **ограничить соль и жидкость**, исключить экстрактивные вещества (**стол № 10**). При сердечной недостаточности — разгрузочные дни.

**3. Лекарства:**

| Группа | Препараты |
|---|---|
| **Антибиотики** | **пенициллин** 1,5–2 недели, потом **бициллин-5** каждые 2–4 недели (750 000 – 1 500 000 ЕД по возрасту) |
| **НПВС** | индометацин, диклофенак |
| **Базисные (хинолиновые)** | хлорохин (хингамин, делагил), гидроксихлорохин (плаквенил, 0,05–0,2 г) — 1 раз в день **после ужина**, от нескольких месяцев до нескольких лет |
| **Глюкокортикоиды** | в тяжёлых случаях. При больших дозах добавляют препараты **калия** (панангин, аспаркам) |
| **Симптоматические** | сердечные гликозиды, эуфиллин, диуретики, кардиотропные средства |
| **При хорее** | + барбитураты, бромиды, малые транквилизаторы (элениум, триоксазин), антигистаминные, витамины группы В |

Также: санация хронических очагов инфекции, физиотерапия.

> ⚠️ **В источнике:** доза хлорохина напечатана как «0,060,25 г» — это опечатка (вероятно, 0,06–0,25 г). Дозы для экзамена медсестры обычно не нужны.

## 6. Роль медицинской сестры

### А. Уход за ребёнком с ВПС

- **правильный режим дня**, как можно больше быть на **свежем воздухе**;
- **рациональное питание**; контролировать **объём пищи**;
- по показаниям **ограничить соль и жидкость**;
- **оберегать от инфекций**;
- **щадящее закаливание**;
- лечебная физкультура **под медицинским наблюдением**;
- санаторное лечение (ревматологические, кардиологические санатории).

**Физкультура:** дети без выраженной сердечной недостаточности могут заниматься ЛФК и ходить на уроки физкультуры в **подготовительной группе**. ❌ Запрещены: упражнения с большим напряжением, спортивные секции, соревнования.

### Б. План сестринского ухода при тетраде Фалло (из ситуационной задачи)

**Нарушенные потребности:** дышать, есть, двигаться, играть, быть здоровым.

**Проблемы:**
- настоящие: одышка, одышечно-цианотические кризы, цианоз, непереносимость физических нагрузок, снижение аппетита, задержка физического развития;
- потенциальные: декомпенсированная сердечная недостаточность, риск смерти во время криза, резкое отставание в развитии;
- **приоритетная:** непереносимость физических нагрузок из-за сердечной недостаточности.

**Цели:** краткосрочная — за день одышка и цианоз уменьшатся; долгосрочная — к выписке ребёнок лучше переносит нагрузки, улучшится аппетит.

**Сестринские вмешательства:**
1. Поместить ребёнка в **светлую, просторную палату**.
2. **Проветривать палату каждые 2 часа по 20 минут**.
3. Удобное положение в постели с **возвышенным головным концом**.
4. Организовать уход так, чтобы был **длительный отдых**.
5. Посоветовать матери продукты, богатые **калием**.
6. Вводить и отменять **дигоксин** только по назначению врача.
7. Вводить **калий** по назначению врача и по правилам: внутрь — **смешивать с соком** (меньше раздражает кишечник); внутривенно — **разводить** (профилактика остановки сердца).
8. Увеличить объём жидкости по назначению врача.
9. Наблюдать за состоянием: **активность, цвет кожи, ЧДД, пульс, АД**.
10. Контролировать **диурез и отёки**.
11. Максимально быть на свежем воздухе.
12. Кормить **по часам**, запретить сладости между кормлениями.

### В. Работа поликлиники и участковой медсестры

**Задачи поликлинической службы при ВПС:**
1. **раннее выявление** детей с ВПС;
2. **систематическое наблюдение**;
3. вместе с кардиохирургом определить **оптимальный срок операции**;
4. своевременно назначить **консервативную терапию**;
5. решить вопросы **режима**;
6. провести **оздоровление**.

Дети с ВПС наблюдаются у **участкового педиатра вместе с кардиохирургом**.

**Участковые медсёстры (под контролем педиатра):**
- приглашают детей в поликлинику по графику;
- объясняют родителям цели и задачи диспансерного наблюдения;
- проводят профилактическое консультирование, коррекцию факторов риска;
- ведут **контрольную карту диспансерного наблюдения — форма № 030/у**.

**Наблюдение после операции (при хорошем результате):**

| Направление | Рекомендации |
|---|---|
| **Профилактика инфекционного эндокардита** | ЛОР-врач и стоматолог **2 раза в год**, санация очагов инфекции. При ОРВИ с температурой **больше 3 дней** — антибиотики |
| **Индивидуальная реабилитация** | При признаках инвалидности |
| **Прививки** | **Через год** после операции |
| **Физические нагрузки** | 3–6 месяцев — специальная подгруппа «Б», потом «А», потом подготовительная группа, **через год — основная** |
| **Режим** | «Домашний» 1–3–6 месяцев после операции (индивидуально) |
| **Санаторий** | Каждый год, местный кардиологический санаторий |

**Когда снимают с диспансерного учёта:**

| Операция | Кардиоцентр | Медицинские организации |
|---|---|---|
| Эндоваскулярные операции (закрытие ОАП, ДМПП, баллонные процедуры при стенозе лёгочной артерии) | 3 года | 5 лет |
| Ушивание и пластика средних ДМЖП без лёгочной гипертензии | 3 года | 5 лет |
| Пластика больших ДМЖП с лёгочной гипертензией | 5 лет | до 18 лет |
| Радиочастотная абляция при нарушениях ритма | 2 года | 3 года |

**Не снимают с учёта** после операций по поводу: **коарктации аорты, тетрады Фалло, аортального стеноза**, протезирования клапанов, сложных ВПС, после имплантации электрокардиостимулятора.

### Г. Уход при ревматизме

**Главное:** **правильный режим и уход с первых дней болезни** — так предупреждают осложнения на сердце.

- **полный покой, постельный режим** во время атаки;
- тёплое помещение (**18–20 °C**), проветривать осторожно, **без сквозняков**, ребёнка укрыть;
- умывать **тёплой водой**;
- лекарства давать **точно и в полной дозе**;
- ангину, грипп и другие болезни лечить **сразу**;
- наблюдать: внешний вид, ЧДД, пульс, АД, температура;
- диета: стол № 10, меньше соли и жидкости, продукты с калием.

**План ухода при ревматической хорее (из задачи):**
- отдельная палата, регулярное проветривание;
- **кормить, одевать и раздевать** ребёнка;
- говорить **спокойным тоном**;
- выполнять назначения врача (вольтарен, успокаивающие, пенициллин 2 недели, потом бициллин);
- наблюдать за состоянием (вид, ЧДД, пульс);
- уход за кожей: обтирание, смена белья.

**При ревматическом полиартрите (из задачи):** приоритетная проблема — **боль в суставе**; потенциальная проблема — **ревматический порок сердца**.

### Д. 🚨 Неотложная помощь (из ситуационных задач)

| Состояние | Признаки | Что делает медсестра |
|---|---|---|
| **Одышечно-цианотический криз** | Одышка, усиление цианоза, тахикардия, возбуждение | Вызвать врача. **Кислород**. Покой. По назначению врача: промедол, обзидан, натрия гидрокарбонат 4 %. **Не давать** гликозиды и диуретики. **Дополнительная информация:** придать положение с прижатыми к животу коленями |
| **Коллапс** | Резкая бледность, липкий холодный пот, нитевидный пульс, АД 60/30, потеря сознания | Уложить с **приподнятым ножным концом**. Свободное дыхание. **Вызвать врача через помощника**. **Согреть**. Измерить АД. Дать вдохнуть **нашатырный спирт**. По назначению врача — **кордиамин или адреналин** подкожно |
| **Обморок** | Бледность, холодные конечности, короткая потеря сознания, АД снижено | Уложить с **приподнятым ножным концом**. Освободить от тесной одежды. **Нашатырный спирт**. Побрызгать лицо и грудь **холодной водой**. Оценить АД и пульс, вызвать врача. По назначению — **кордиамин или кофеин** подкожно |

### Е. ❌ Ошибки, которых нельзя делать

| Ошибка | Правильно |
|---|---|
| Считать пульс у ребёнка 15 или 30 секунд | Считать **60 секунд** |
| Давать гликозиды и диуретики при кризе | Противопоказано. Основа — кислород |
| Вводить калий внутривенно неразведённым | Только в разведении |
| Разрешать ребёнку с ВПС спортивные секции и соревнования | Только ЛФК и подготовительная группа |
| Делать прививки сразу после операции | Через год |
| Снять с учёта ребёнка после операции по поводу тетрады Фалло или коарктации | Они **не снимаются** с учёта |
| Разрешить ребёнку с ревматической атакой ходить | Полный покой, постельный режим |
| Проветривать со сквозняком при ревматизме | Осторожно, ребёнок укрыт |
| Уложить ребёнка при обмороке с поднятой головой | Поднять **ножной** конец |

## 7. Осложнения и профилактика

### А. ВПС

**Осложнения:**
- **сердечная недостаточность**;
- **гипоксемические кризы**, гипоксическая кома, судороги;
- **тромбозы**;
- анемии;
- частые пневмонии и респираторные инфекции;
- отставание в физическом развитии;
- **инфекционный эндокардит**;
- лёгочная гипертензия;
- терминальная фаза → смерть.

**Профилактика ВПС:**
- здоровый образ жизни матери: без **алкоголя, наркотиков**, курения;
- защита беременной от инфекций и вредных экологических факторов, особенно на **2–8-й неделе**;
- лечение болезней матери.

**Профилактика осложнений:** раннее выявление, диспансерное наблюдение, операция вовремя, защита от инфекций, санация очагов инфекции, аспирин и дезагреганты по назначению.

### Б. Ревматизм

**Осложнения:**
- **приобретённый порок сердца** (ревматизм — главная причина пороков сердца);
- сердечно-сосудистая недостаточность;
- повторные ревматические атаки.

**Профилактика:**
- лечить ангину и другие стрептококковые инфекции **сразу и до конца**;
- санация хронических очагов инфекции;
- избегать переохлаждения;
- **вторичная профилактика — бициллин-5**;
- правильный режим и уход с первых дней болезни.

## 9. Вопросы и ответы для ревизии

1. **Когда формируется сердце?**
   На 2-й неделе внутриутробной жизни. Сокращается с 6–8-й недели. Выслушивается с 18–20-й недели.

2. **Назовите особенности кровообращения плода.**
   Три круга кровообращения (дополнительный плацентарный). Три плодовые коммуникации: Аранциев проток, Боталлов проток, овальное окно.

3. **Что такое порок сердца?**
   Стойкое патологическое изменение в строении сердца, нарушающее его функцию.

4. **Когда и почему формируются ВПС?**
   На 2–8-й неделе беременности из-за нарушения эмбриогенеза или после внутриутробного эндокардита.

5. **Назовите группы ВПС.**
   I — с обогащением малого круга; II — с обеднением малого круга; III — с обеднением большого круга; IV — без нарушений гемодинамики.

6. **Какие пороки относятся к I группе?**
   ОАП, ДМПП, ДМЖП.

7. **Какие пороки относятся ко II и III группам?**
   II: изолированный стеноз лёгочной артерии, болезнь Фалло. III: коарктация аорты.

8. **Назовите три фазы течения ВПС.**
   Первичной адаптации, относительной компенсации (через 2–3 года), терминальная.

9. **Назовите общие клинические признаки ВПС.**
   Цианоз, одышка, шум над сердцем, увеличение границ сердца, частые респираторные инфекции и пневмонии, отставание в физическом развитии.

10. **Какая ЧСС у новорождённого? Как считать пульс у детей?**
    120–140 в минуту, к 5 годам — 100. Считать 60 секунд, потому что пульс аритмичный.

11. **Как рассчитать АД у ребёнка старше года?**
    АД макс = 102 + 0,5·n, где n — возраст в годах. АД мин = ½–⅔ от максимального.

12. **Какой шум при ОАП? Какой пульс и давление?**
    Систолический «машинный» шум. Пульс скачущий. Минимальное АД низкое.

13. **Какой порок самый частый? Какие у него формы?**
    ДМЖП (20–30 %). Высокие дефекты в мембранозной части и малые дефекты в мышечной части (болезнь Толочинова–Роже).

14. **Из чего состоит тетрада Фалло?**
    Стеноз лёгочной артерии, ДМЖП, транспозиция аорты вправо, гипертрофия правого желудочка.

15. **Назовите признаки тетрады Фалло.**
    Одышка и цианоз с рождения, поза на корточках, «барабанные палочки» и «часовые стёкла», отставание в развитии, грубый систолический шум, повышены гемоглобин и эритроциты.

16. **Что такое одышечно-цианотический криз?**
    Приступ одышки с тахикардией и усилением цианоза. Ребёнок возбуждён, может быть обморок, потом гипоксическая кома с судорогами.

17. **Что является основой лечения одышечно-цианотического криза?**
    Оксигенотерапия. Также коррекция ацидоза и снятие спазма лёгочной артерии (промедол, обзидан).

18. **Какие препараты противопоказаны при кризе?**
    Сердечные гликозиды и диуретики.

19. **Как лечат ВПС?**
    Единственный метод — операция: радикальная или паллиативная. Лучший срок — II фаза (3–12 лет).

20. **Назовите задачи консервативной терапии ВПС.**
    Неотложная помощь при сердечной недостаточности и кризах, поддерживающее лечение, профилактика тромбозов, лечение анемий.

21. **Что входит в уход за ребёнком с ВПС?**
    Режим с пребыванием на свежем воздухе, рациональное питание, контроль объёма пищи, ограничение соли и жидкости по показаниям, защита от инфекций, щадящее закаливание, ЛФК, санаторное лечение.

22. **Назовите задачи поликлинической службы при ВПС.**
    Раннее выявление, систематическое наблюдение, определение срока операции вместе с кардиохирургом, консервативная терапия, вопросы режима, оздоровление.

23. **Какой метод самый важный в диагностике пороков сердца?**
    Ультразвуковое исследование сердца.

24. **Когда делают прививки после операции на сердце?**
    Через год после операции.

25. **Дайте определение ревматизма.**
    Системное воспалительное заболевание соединительной ткани с преимущественной локализацией в сердечно-сосудистой системе.

26. **Что вызывает ревматизм?**
    β-гемолитический стрептококк группы А. Болезнь начинается через 1,5–2 недели после стрептококковой инфекции.

27. **Назовите основные диагностические критерии ревматизма.**
    Кардит, полиартрит, хорея, ревматические узелки и аннулярная эритема, связь со стрептококковой инфекцией.

28. **Какие суставы поражаются при ревматическом полиартрите?**
    Крупные суставы конечностей, симметрично.

29. **Чем проявляется малая хорея?**
    Гиперкинезами, гипотонией мышц, нарушением координации, эмоциональной неустойчивостью.

30. **Чем проводят вторичную профилактику ревматизма? Какая главная мера ухода?**
    Бициллином-5. Главная мера — правильный режим и уход с первых дней болезни.

**Ответы на тесты из методички** (в документе правильные ответы не отмечены, это мои ответы по тексту лекции):

**ЭКГ — наложение электродов:**

Правило: «**К**аждая **Ж**енщина **З**лее **Ч**ёрта».

| Цвет | Куда |
|---|---|
| **К**расный | правая рука |
| **Ж**ёлтый | левая рука |
| **З**елёный | левая нога |
| **Ч**ёрный | правая нога |

На грудную клетку — **6 электродов** (V1–V6).

Преподаватель может попросить **нарисовать нормальную ЭКГ** и объяснить зубцы. Она также говорила о «**кошачьей спинке**» на ЭКГ (признак инфаркта) и о «золотых» первых двух часах (это место в записи неясное).

**Дополнительная информация — зубцы ЭКГ:**

| Элемент | Что означает |

| Комплекс **QRS** | сокращение (возбуждение) желудочков |
| Сегмент **S–T** | желудочки полностью возбуждены |
| Зубец **T** | восстановление (расслабление) желудочков |
