# Таблицы для быстрого повторения. ПМСП

## Лекция 1. Первичная медицинская помощь

| Тема | Главное |
|---|---|
| Что такое ПМСП | Ядро здравоохранения. Первый контакт человека с врачом. На неё приходится 80% посещений ЛПУ. |
| Принципы ПМСП | Доступность. Бесплатность. По месту жительства. Обязательный комплекс мероприятий. |
| Охрана здоровья | Все меры (правовые, медицинские, социальные и др.), чтобы сохранить и укрепить здоровье. |
| Законы | Конституция ст. 41. ФЗ № 323-ФЗ (2011). ФЗ № 326-ФЗ (ОМС). Приказы № 487, № 633. |
| Ст. 33 (ПМСП) | Профилактика, диагностика, лечение, реабилитация. Работает по участковому принципу. |
| Кто оказывает | Доврачебная: фельдшер, акушер. Врачебная: терапевт, педиатр, ВОП. Специализированная: врачи-специалисты. |
| Финансирование | ОМС. Федеральный и региональные бюджеты. Другие источники. |

**Виды помощи**

| Вид | Что это |
|---|---|
| Доврачебная | Помощь средних медработников |
| Квалифицированная | Помощь врачей |
| Медико-социальная | Для людей с социально значимыми болезнями |
| Первая | Самопомощь и взаимопомощь на месте |
| Неотложная | Внезапные острые состояния. Дом или поликлиника |
| Скорая | Угроза жизни. Бригада скорой помощи |
| Специализированная | Высшая форма. Врачи-специалисты |
| Стационарная | Больница, госпиталь, роддом |
| Экстренная | Острые болезни и травмы на всех этапах |

**Новые формы внебольничной помощи**

| Форма | Особенности |
|---|---|
| Дневной стационар | Не нужно круглосуточное наблюдение |
| Хирургический стационар одного дня | Операция, потом наблюдение и перевязки |
| Стационар на дому | Лечение дома. Централизованный (12–14 больных в день) и децентрализованный метод |
| Центр амбулаторной хирургии (ЦАХ) | Амбулаторная хирургия в большом объёме |
| Хоспис | Помощь умирающим. Первый современный: С. Сондерс, Лондон, 1967. В России: Санкт-Петербург, 1990 |

## Лекция 2. Учреждения ПМСП

| Учреждение | Что делает |
|---|---|
| Поликлиника | Помощь приходящим больным и на дому. 80% больных лечатся только там |
| Амбулатория | Приём по одной или нескольким специальностям |
| Медсанчасть | Помощь на крупных предприятиях. Есть поликлиника, стационар, здравпункт, профилакторий |
| Здравпункт | Подразделение на предприятиях и в учебных заведениях |
| Женская консультация | Гинекология и наблюдение беременных |
| Станция скорой помощи | Неотложная помощь круглосуточно |

**Классификация поликлиник**

| По чему | Виды |
|---|---|
| По организации | Объединённые со стационаром / самостоятельные |
| По территории | Городские / сельские |
| По профилю | Для взрослых и детей / только взрослые / только дети / специализированные |

**Структура городской поликлиники**

| Часть | Состав |
|---|---|
| Руководство | Главный врач, заместители |
| Регистратура | Со столом справок |
| Лечебно-профилактические | Терапия, хирургия, травматология, женская консультация, диспансерное отделение и др. |
| Вспомогательные | Рентген, лаборатория, функциональная диагностика, эндоскопия, кабинет статистики |

**Стационар:** оптимальная больница общего типа — 600–800 коек. Классификация больниц: по профилю, по организации (с поликлиникой или без), по объёму. Преемственность: обмен информацией между поликлиникой и стационаром, участие врачей стационара в диспансеризации.

| Режим | Рабочие смены | Круглосуточно |

**Помощь гражданам с правом на соцуслуги**

| Пункт | Что делают |
|---|---|
| Карта | Ставят литеру «Л» |
| Диспансерное наблюдение | 1 раз в год — осмотр. 1 раз в полгода — анализы. 1 раз в 3 месяца — патронаж медсестры |
| Документы | Контрольная карта (030/у). Паспорт врачебного участка |

**Охрана труда медсестры**

| Раздел | Главное |
|---|---|
| Опасности | Удар током. Пары ртути. Инфекции |
| Запрещено | Оставлять пациентов и лекарства без присмотра. Тяжёлое на шкафах. Включённые приборы. Закрывать кабинет на ключ при людях |
| Перед работой | Инструктаж. Проветрить. Спецодежда. Свет не менее 300 лк. Температура 21–23 °C. Вымыть руки |
| Текущая уборка | 1–2 раза в день. Метод «двух вёдер» |
| Генеральная уборка | 1 раз в неделю |

## Лекция 4. Диспансеризация

| Тема | Главное |
|---|---|
| Определение | Система активного наблюдения за здоровьем определённых групп населения. Цель — предупредить болезни |
| Основа | Диспансерный метод: постоянное наблюдение за людьми на учёте |
| Цель для здоровых | Сохранить и укрепить здоровье |
| Цель для больных | Выявить болезнь рано, предупредить обострения |
| Главная цель | Меньше заболеваемость и инвалидность |
| Виды | 1) после острых болезней 2) хронические больные 3) декретированные контингенты 4) здоровые люди |
| Дополнительная диспансеризация | Часть нацпроекта «Здоровье». Для работающих |
| Что выявляют | Болезни сердца и сосудов, онкология, туберкулёз, диабет, опорно-двигательный аппарат |
| Обследования | Флюорография (1 раз в год). Маммография (1 раз в 2 года). ЭКГ. Анализы. Холестерин. Сахар. УЗИ простаты |
| Специалисты | Терапевт, невролог, хирург, офтальмолог, эндокринолог, гинеколог, уролог |
| Итог | Паспорт здоровья |

**Работа участковой медсестры**

| Течение болезни | Как часто осмотр |
|---|---|
| Компенсированное | 2 раза в год |
| Субкомпенсированное | 4 раза в год |
| Декомпенсированное | Постоянно (каждый месяц) |

| Документ | Для чего |
|---|---|
| Карта амбулаторного больного (УФ-025/у) | Ставят букву «Д». Результаты обследований. Этапный эпикриз в конце года |
| Контрольная карта (УФ-030/у) | Хранится у терапевта в картотеке. При двух болезнях — отдельные карты |
